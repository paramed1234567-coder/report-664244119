เนื้อหาสัมมนา (Productivity OS)

Productivity OS

การจัดระเบียบความคิดและงานอย่างเป็นระบบด้วยเทคโนโลยี ช่วยเพิ่มประสิทธิภาพในการทำงานและการเรียนรู้อย่างก้าวกระโดด

1.Notion

เครื่องมือการวางแผนชีวิตหลักการทำงานคล้ายโพสอิทแต่สามารถใส่ฟังก์ชั่นเพิ่มเติมได้ ใช้แนวคิดรูปแบบ building block

2.Workflow manager

เครื่องมือจัดระเบียบและบริหารจัดการงานออนไลน์ที่เน้นการมองเห็นเป็นภาพ ใช้แนวคิดรูปแบบ kanban

3.Researcher

แอปพลิเคชันจัดระเบียบข้อมูล จดบันทึก และบริหารจัดการงานดิจิทัล ที่ถูกออกแบบมาภายใต้แนวคิด ใช้แนวคิดรูปแบบ Remember everything

4.Quest planner

แอปพลิเคชันสำหรับจัดการตารางงานและความเป็นระเบียบในชีวิตแบบครบวงจร ใช้แนวคิดรูปแบบ Task management

5.Task manager

แอปพลิเคชันสำหรับการบริหารจัดการงานและจัดทำรายการสิ่งที่ต้องทำ Cloud-based Sync ใช้แนวคิดรูปแบบ Task management
